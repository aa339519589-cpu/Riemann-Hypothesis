## 复核原则

- 仅以**可复算证明、严格证书和适用量词**决定结论状态。
- 显式区分：严格解析证明、条件性判据、有限维计算、数值探索、形式化验证和不可恢复资料。
- 不把“等价于 RH”改写成“RH 已解”；不把连续谱定位等同于临界谱隙已证。
- 旧报告任何成果都可被新的审查推翻；不能以历史自述自动认证。
- 实际平台故障和数学证明有效性分别记录。

6.3   真实素数跳跃破坏半轴随机单调性

  由于核与测度都反射对称，可把偶函数视作半轴函数。设生成元为 G+ 。对 x < z，到 (z, ∞) 的
跳率为
                 Tz (x) = G+ 1(z,∞) (x).
阈值离开 x，所以这个跳率有限；也可用光滑递增近似函数定义。

定理 6.3. 半轴上的实际 Markov 半群不保持随机单调序。

证明. 取
                    z = log 2,     x0 = log(3/2),      0 < x0 < z.
n = 3 的一个真实跳跃在折叠后落到 |x − log 3|。当 x 从 x0 左侧越过右侧时，这个目的点从 z 上方
移到下方。因此 Tz (x) 有一个严格向下的跳跃，其大小为

                             log 3      Φ(log 2)
                              √            1           > 0.                (40)
                                3  2 cosh( 2 log(3/2))

Archimedean 部分在该处连续。其他素数幂的折叠目的点没有同时穿过阈值：另一种可能要求整数
n = 4/3，而同种穿越只对应 n = 3。在 x0 的紧邻域内，大素数尾一致收敛，所以不能由无限多个
其他跳跃隐藏掉这一向下间断。
  取足够小的 h > 0，x− = x0 − h < x+ = x0 + h < z，便有 Tz (x− ) > Tz (x+ )。把阈值指示函数
用足够窄的光滑递增函数 f 逼近，同时令 f (x− ) = f (x+ ) = 0，该严格不等式仍保持。
   如果半群保持随机单调序，在包含 x− , x+ 且 f 恒为零的小区间上，(Pt f − f )/t 对每个 t > 0
都有非递减代表。非递减函数构成的锥在局部 L2 中闭合；取生成元的 L2 极限，便要求 G+ f 在该
区间几乎处处非递减。这与左右两个小邻域上的严格反向不等式矛盾。这个论证不需要额外假定点
态 Feller 版本。

  因此也不能直接套用一个需要随机单调半群的谱排序论证。这个结论来自实际 n = 3 项，不是
替代核或人为注入的模拟零点。

                     8 独立检查与尚未完成的承重步骤

8.1   本轮对自身推导的检查

      主要易错点逐项如下。

 1. 导数递推采用 5/2 与 2u∂u ，不是旧 t 坐标中的 5 与 4u∂u ；首项尺度及常数因此与第三轮统一。

 2. 喷射消去作用于第一模态多项式，但 g 始终由实际 Φ 的导数组成。其余模态由共同 Gaussian
    界控制，未被删除。

 3. 增长阶结论使用矩阵逆、精确除法和导数范数的共同界。仅有固定阶渐近不够。

 4. Q(v) = Q(r) 来自零作用身份，不能从它推出任意 Q(f ) ≥ 0。谱结论明确只有上界。

 5. 在跳跃表示中，概率测度是 2Φ cosh(x/2)dx；遗漏因子二会把 1/2 临界常数和曲率比同时算错。

 6. 一般函数的形式身份保留 − 12 |ν(τ q)|2 ；只在偶子空间才将它删去。

 7. 1/2 的无限重数不排除更低的正谱。局部曲率失败与随机单调性失败也不等于 Poincaré 不等式
    失败。

 8. 必要负平移尺度以成功极限为前提；没有把这个必要条件倒用成合法平移或收敛证明。


8.2   最终状态

已得到的解析内容：边界喷射线性系统、固定阶准确正主项、支持增长阶的共同误差控制、超越每
个固定多项式损失的实际连续试探序列、固定有限秩剔除后的上侧障碍、成功负平移的更强必要尺
度、准确的正跳跃表示、临界本征值的无限重数、真实生成元的曲率与随机单调性两个具体障碍。
没有得到：真实连续 Weil 形式在全部偶测试上的非负性；足够的全窗口次指数负谱下界；临界方差
不等式 (32)；合法且收敛的无界窗口变分选态；全部 Dβ (n, r) 的正性；RH 的完整证明。
  主缺口现在可以用两种准确语言表达：原来的连续下界，或者本轮的临界 1/2 方差不等式。两
者是同一承重问题，不是通过改名减少了证明难度。继续抬高中心试探态的修正阶数，只会改善上
侧估计，不能被当成下界已经向前推进。

# 完整标记行反射界的数学核验

核验对象为 `MARKED_ROW_REFLECTION.md` 的完整物理行、全尺度反射界及
原标记 Euler 去卷积推论。固定源仍是 `openai/math` 的
`fd4aeeb2ee4fc729c18d98444fed42fd0529eeeb`；新增推导不使用 7/8 无零定理。

## 1. 实际对象和源匹配

原完整行的变量为平方自由 \(c\) 与任意 \(n\)，指标是 \(cn^3\)，允许
共享素数。\(\overline G\) 先按固定 ray 群作有限 Fourier 展开，不能把
\(G\) 自身直接视为乘法字符；其总系数质量固定。原 \(\chi_A(m)\) 的
所有好素因子留在源反射的 moving set 中，包括指数为零模六的素数。
坏素数赋值只按模六进入固定有限 ray 家族，故最终常数与其大小无关。

源反射证明的 Mellin 被积函数是 theta 的水平导数；在每个 cusp 仍为
水平导数，因此常数项被消去。实际行保留了产生该导数的角向权。
整延拓及移线针对完整乘积 \(T=DL_0\)，没有断言两个因子各自整，
也没有套用另一个含零频主项的无角向 cubic Gauss 平均公式。

## 2. 标记合并与统一性

当 \((D,m)\ne1\) 时，原行逐项为零。除此情形，标记素数与原 moving
set 不交。源中未激活零指数分支与缺席分支的同时兼容性对所有
\(h_0\) 成立，故缺席和未激活标量可以先精确相减。
固定标记激活子积 \(E\) 后，所得标量是
\((-1)^{\omega(E)}q_{D/E}^{-1}\)，并保留激活列的 \(q_E^{-1/2}\)。
其他激活素数相位可能依赖整个激活集合，但在这次合并中集合相同，
并未把这些相位丢弃或宣称它们在不同 \(E\) 间抵消。

\(r_m\) 必须逐分支定义为原行素数的激活乘积。双边长度
\((q_{c_F}q_{r_m}q_E)^2/U\) 和原零指数的两个局部成本因此准确。
求和 \(E\) 后是 \(\sqrt{q_D}\sum_{F\mid D}q_F^{-3/2}\)，该和有统一
上界，不产生 \(2^{\omega(D)}\) 或小幂损失。

## 3. cusp 质量、局部成本和全部正尺度

源系数质量按 \(\mu=u\lambda^k n b^3\) 分组。范数壳中每个
\((k,B)\) 的质量为 \(O(\sqrt M,3^{-5k/6}B^{-3/2})\)，两个和收敛。
整除 \(F\mid\mu\) 的每个好素数可分配给 \(n\) 或 \(b\)；理想格点
缩放使每份的密度为 \(1/q_F\)，共有至多 \(2^{\omega(F)}\) 份。
没有要求 \((n,b)=1\)，共享素数的重复计数只扩大上界。

Ramanujan \(j=4\) 列展开后，壳质量因子为
\(3^{\omega(J_4)}/\sqrt{q_{J_4}}\)。反射核壳求和对所有 \(L>0\)
均为 \(O(\sqrt L)\)；将正壳和延至全部整数尺度的两段几何级数
直接证明小于一的尺度，不需要添加 \(1+L\)。

原行每个强制普通素数成本为 \(q_p\)，\(j=4\) 为 \(3\sqrt{q_p}\)，
零指数的两分支成本为 \(1-q_p^{-1}+\sqrt{q_p}\)。所以得到正文的
精确 \(H(m)\)。\(j=4\) 成本不超过 \(q_p\) 当 \(q_p\ge9\)，有限个
更小素理想吸入固定常数；零指数成本在好素数范围内不超过 \(q_p\)。
故 \(H(m)\ll R(m)\le q_m\)，常数不依赖素因子数。

## 4. 去卷积与结论范围

原标记去卷积系数绝对值至多 \(q_a^{-2}\)。两个行界使其每项至多
\(C\min(Aq_a^{-5},Bq_a)\)，其中 \(A=\sqrt U/q_D\)、
\(B=R(m)\sqrt{q_D}/\sqrt U\)。理想计数给分割成本
\(BT^2+AT^{-4}\)；在 \(A/B\ge1\) 取 \(T=(A/B)^{1/6}\)，得到
\(R(m)^{2/3}U^{-1/6}\)，全部标记幂消去。\(A/B<1\) 时直接用原
正项界。这验证了正文 (22) 的全部尺度及统一常数。

此处始终是原 completed-index 标记，不涵盖另行定义的 core 标记。
固定行改善也没有改善既有 \(B^J\) 能量：直接求和原 slots 所得能量
指数超过原 R2 的量为 \(1-6d\ge0\)。没有证明完整 R4、全部非主
高端误差、严格谱增长下降或 RH。

有限复算脚本检查标量合并、指数和平衡幂；解析证明的范围由上述
源匹配、格点计数和无限求和论证确定，不能由脚本通过扩张。

# 二次 dual 的联合 Möbius 列抵消核验

核验对象为 `QUADRATIC_MOBIUS_GAIN.md`。结论仅针对准确第一 Poisson 后的
完整非主二次 core，包含全部物理 \(n\)、两个指定标记与准确 core
去卷积；没有验证完整 R4 或新零点排除。

## 1. 可用的 7/8 输入与实际模数

新增使用的有限阶 Hecke 7/8 无零输入来自固定 `fd4aeeb2`，实际验收
证据是 `FORMAL_INPUT_Q.md`。既有 logarithmic control 加上删除因子
的逆界给缓冲半平面的次幂倒数界。模数必须包含所有删除的 Euler
素数，不能用原始 conductor 掩盖一个任意大的 imprimitive 模数。
倒数在主字符的极点处为可去零值；平滑 Mellin 移线没有留数。

正文的 Möbius 引理是实际 \(\mu\psi\) Euler 级数的移线，范数权产生
\(X^{-1/8+\delta}\)，Mellin 高度只有多项式损失。其紧支撑 Mellin
积分对任意 \(X>0\) 有效，没有有限 Perron 尾，也没有本征源保类假设。

## 2. 全部物理层的自由列相位

直接核对源的 coefficientwise CRT/unit-factor 与 pair-phase 消去。
自由 \(c_1\) 素数避开 \(n_0H'\)，局部表变量为
\(e_0=1,l=j=m=k_s=0\)，对应项为 \(-\eta(p)\chi_p(H')^{-1}\)。
因此列相位确实是 \(\mu(c_1)\eta(c_1)\overline{\chi_{c_1}(H')}\)，
没有未取消的角向或 inverse Gauss 因子。\(n_0\) 的两个 odd 分支
冻结在原 \(E,F\) 数据中，不能删去任一分支。

提取 \(L=\operatorname{lcm}(e,D_0)\) 后，\(c_0\) 的互素 mask 包含
\(LEgn_0hH'\)。其中 \(h\mid\operatorname{rad}r\) 必须计入模数；
\(q_h\le q_r\) 的小幂损失由可和平方层吸收。正文的实际模数界
与这些 masks 一致，固定 ray 展开只有固定总系数质量。

## 3. 联合权重的两项必要条件

全 \(n\) 的 Fourier 参数必须是
\(\sqrt QH'/(b_*scn_0^3)\)，而非 \(n=1\) 的 \(b_*sc\) 分母。
所以在规范范数变量中，\(\lambda=q_{H'}/K_\ell\)，
\(K_\ell=C_\ell q_{n_0}^3/X'\) 与 \(n_0\) 无关。

对数 Fourier 分离必须在积分外保留固定紧支撑乘积 cutoffs，正文
(17) 明确做到这一点。若只反演 profile 并保留无限区间的纯范数幂，
每个模式就不能使用紧支撑 Möbius/第二 Poisson 引理。
在正确 (17) 下，各模式的两处算术系数独立，移动依赖全在联合 smooth
profile 中；其加权 Fourier \(L^1\) 范数统一控制两个高度，并保留原
Schwartz 尾。没有用一个依赖列参数的绝对 \(s\) 界后再声称列抵消。

## 4. 精确幂和完整求和

列质量为 \(C_1^{-1/8+\delta}q_L^{-7/8-\delta}\)，\(\delta\) 的符号为负。
取 \(\kappa=1/8-\delta\) 后，\(q_L\le q_eq_D\) 与原 slot 密度给
\(C_1^{-\kappa}P^\kappa q_e^{-1+\kappa}\)。
Gaussian 尺度中使用 \(T\)，所以得到 \(T^{-\kappa}\)，而非仅适用于
\(T=Z\) 的 \(Z^{-\kappa}\)。原 \(s\) 支持使 \(e\) 的上界为
\(Y'/(q_Fq_gq_j^2q_f)\)，理想计数准确消去 \(g^\kappa\)。

原两支权乘新增因子后为
\(\prod_{p\mid v}(1+q_p^{-2+4\kappa}+q_p^{-1+2\kappa})\)。
这是有限乘积的任意小幂界；没有将 \(-3/4\) 的无限素数和称为收敛。
平方层为 \(q_r^{-5+6\kappa}\le q_r^{-17/4}\)，除数/mask 模数损失
和 Gaussian/Fourier 尾均仍可求和。

原 core 去卷积提升频率为 \(Hb^6\)，保持同一非主二次 core。
大尺度部分的 \(q_b^{-17/4}\) 和收敛，小尺度尾为
\((Y'/Z)^{2/3}\)，强于所需 \((Y'/Z)^{1/8}\)。
这验证了改善对准确去卷积的传递，不推广未经证明的负指数低端界。

## 5. 归一化与限制

在原尺度，线性分支指数为 \(175/384-5d/8\)，\(Q^{-1/2}\) 后为
\(5/128+3d/8\)，原 tuple 补偿后为 \(5/128-d/8\)。故全有限补偿的
该类型为 \(O(Z^{5/128+\epsilon})\)，距临界低端仍差 \(29/128\)。
互素展开的 \(\mu(e)\) 与提取列的 \(\mu(L)\) 合并为
\(\mu(D_0/(D_0,e))\)，不能凭它宣称第二次自由 Möbius 抵消。
本文没有覆盖主/unit-core 或一般 cubic/sextic 核，没有给完整高端
非主行比较，更没有完成 RH。

后续 Part IV 的公共列接口已有大筛范数 \(O(Z^\epsilon\sqrt{1+V/L_c})\)。
逐点 Möbius 界先展开列 slots，成本为 \(P_C^\kappa\)；在正文第 8 节
主导尺度，其上界幂为 \(7/192+(19/24)\delta\)，所以直接取最小值
没有改善大筛的 \(O(1)\) 主导预算。这个计算不是实际范数的下界。
正文准确注明后续报告的更强 \(-1/32\) 界，没有把本文 \(5/128\)
称为当前最强，也没有把两个节省相乘。

配套代码只复算有理指数、LCM 的全部局部 membership 类和缓冲幂符号。
独立解析核验的效力来自以上源匹配和联合权重论证，不能由代码通过代替。

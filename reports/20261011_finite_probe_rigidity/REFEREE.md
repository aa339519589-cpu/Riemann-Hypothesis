# 独立交叉核验：有限读数与任意薄条带的额外因子根

日期：2026-10-11。审查对象：`finite_probe_rigidity.md`；实际读取稿件 SHA-256：`432489dc748b81b98c340cd03061f4298cdca2da7fee4882a81c0b3951639353`。

本审查先收到定理陈述并独立检查定理 1 的有限维论证；随后阅读完整交付稿，重算定理 3 的统一正性、缩放和所有显式 Rouché 常数。结论：所检查断言成立。它们是精确范围的反模型/刚性辅助结果，不是 RH 排零定理，也没有给出 ζ 的真实离轴零点。

## 1. 定理 1 的量词和域

在 `V=span_R{Φ^(2n)}` 上，允许的每个线性泛函只须在 V 有定义。J 个读数加 `R(1/4)=0` 共 J+1 个齐次条件；次数 ≤J+1 的多项式空间维数 J+2，故有非零解。不存在非零常数解。

映射 `R→R(∂²)Φ` 单射：Fourier 变换是 `R(−z²)Ξ(z)`，而 Ξ 不恒为零。选 R 的最高项系数为正后，真实 theta 尾给

`R(∂²)Φ/Φ ~ a_N(4π²)^N e^(4N|x|) → +∞`。

该比值连续且偶，因此有有限全局下界。充分小的正 ε 保证 `Φ+εR(∂²)Φ ≥ Φ/2`。源方程由合法微分和 `R(1/4)=0` 保持；有限读数由线性保持。论证不需要所给泛函的拓扑连续性。

范围正确：这是无预定次数上界的有限多项式族；不能据此否定固定有限维模型的识别。该一般定理自身不保证新增根非实，后者由不同的定理 3 构造完成。

## 2. 定理 3 的喷射与全参数正性

取实首一平方多项式 B=R²，并在 `1/4` 和所有指定 `−z_j²` 及其共轭处置入足够重数，可使

`P_γ(t)=1+cγ^(−4)B(t)(t+γ²)²`

满足 `P_γ(1/4)=1`，且 `(P_γ(−z²)−1)Ξ(z)` 在每个指定点有要求的零喷射。z_j=0 处的平方复合只增加消失阶；无需假设 Ξ 在指定点非零。

令 `G_j=∂^(2j)B(∂²)Φ/Φ`。每个 G_j 的最高微分阶为偶，最高系数正，因此连续、偶且两尾趋正无穷。使用 `G_j≥−M_j`，取

`C=M_0+2M_1+M_2`，`c=1/(2(1+C))`，

准确得到对全部 γ≥1，

`K_γ/Φ=1+c(G_0+2γ^(−2)G_1+γ^(−4)G_2)≥1−cC>1/2`。

给出的显式模态常数也成立：若模态多项式 `A(u)=a_Lu^L+Σ_{k<L}a_ku^k`、a_L>0，取

`U=max(3,1+2Σ_{k<L}|a_k|/a_L)`。

u≥U 时高项支配；3≤u≤U 时分母 `2u−3≥3`，故 `A(u)/(2u−3)≥−(1/3)Σ_{k<L}|a_k|U^k`。实际 G_j 是这些模态比值的正权平均，所给 M_j 因而确为全轴下界。

## 3. Rouché 缩放与常数逐项重算

设 d=deg B，为偶数且 d≥2。令

`z=γ+γ^(1−d)u=γ(1+v)`，`v=γ^(−d)u`。

则原多项式因子准确成为

`P_γ(−z²)=1+cu² B_norm(u)(2+v)²`，

其中 `B_norm=B(−γ²(1+v)²)/γ^(2d)`。d 偶保证其最高项极限为 1，而非 −1。

在 `|u|≤1/√c` 上，令 `a=γ^(−d)/√c`。稿件阈值 `γ≥2/√c`、d≥2 保证 a≤1/γ。若 β 为 B 非最高项系数绝对值之和、γ≥β，则

`|B_norm−1| ≤ (1+a)^(2d)(1+βγ^(−2))−1 ≤ (4d+2)/γ`。

最后一步可用 γ≥4d：`(1+1/γ)^(2d)≤exp(2d/γ)≤1+4d/γ`，并吸收交叉项。稿件更强阈值当然覆盖它。

另有 `|(2+v)²−4|≤5/γ`、`|2+v|²≤9`、`|cu²|≤1`。所以

`|P_γ(−z²)−(1+4cu²)| ≤ [9(4d+2)+5]/γ=(36d+23)/γ`。

γ≥72d+46 使此差 ≤1/2。在以 `u_±=±i/(2√c)` 为圆心、半径 `1/(4√c)` 的圆上，

`|1+4cu²|=4c|u−u_+||u−u_-|≥3/4`。

两圆不相交，每圆内极限多项式恰有一个简单根。因此 Rouché 确认每圆内原缩放因子也恰有一个根，并给

`γ^(1−d)/(4√c) < |Im z| < 3γ^(1−d)/(4√c)`。

因 d≥2，γ 可再增大以进入任何给定薄条带。实 z 时 `B(−z²)≥0`，所以因子 ≥1，无实根；不会把这些根误算为实轴根。

## 4. 必须保留的范围

- 新根是修改核的额外多项式因子根，绝不是新发现的 ζ 离轴零点。
- 与 Ξ 的可能重合无需排除：乘整函数不可能抵消该零点。
- 同时匹配任意有限 Fourier/Mellin 喷射并制造薄条带根成立；“任意有限空间读数同时制造这些根”没有被这一个构造证明，主稿已正确区分。
- 相对尾有界和固定 Γ 商右端有界，能排除整个有限微分变形族；它们不自动成为真实亚临界本征源的 Dirichlet 保类条件。
- 本审查只完成数学交叉核对，没有形式化内核验证，没有将有限代数或局部矩阵认证升级为 RH 证明。

## Reproduction

Requirements: Python 3, NumPy, and mpmath. The directed binary64 column kernel
assumes ordinary IEEE754 elementary NumPy arithmetic without flush-to-zero.
Run from this directory. First decompress and VERIFY the complete head input:

    python -c "import gzip,hashlib,pathlib; p=pathlib.Path('unrepaired_head_kernel_intervals.json'); b=gzip.decompress(pathlib.Path(str(p)+'.gz').read_bytes()); assert hashlib.sha256(b).hexdigest()=='5b6d56a17d725aeb7fba30495032807f60facad2da84613f8403288fea87e8d9'; p.write_bytes(b)"

Light checks against the frozen mathematical inputs:

    python check_filtered_bessel_gamma_floor.py
    python check_filtered_bessel_tail_masses.py
    python check_filtered_k3_infinite_debit.py --mass-json filtered_bessel_tail_mass_enclosures.json
    python certify_filtered_main_force_variation.py
    python check_filtered_mixed_absolute_remainders.py
    python certify_filtered_true_source_schur.py

The final command must report all positive interval pivots and the stated
single-source bound. This assembly is much cheaper than regenerating all
mixed columns. To regenerate the endpoint separately:

    python certify_filtered_main_force_endpoint.py --out regenerated_endpoint.json
    python certify_filtered_true_source_schur.py --endpoint regenerated_endpoint.json

Full source-cell and mixed-column regeneration, which is the heavier route:

    python certify_filtered_bessel_moments.py --stop 128 --out filtered_bessel_main_moments.json
    python certify_filtered_bessel_moments.py --prefix-only --stop 128 --out filtered_bessel_prefix_moments.json
    python certify_filtered_bessel_onset_cells.py
    python check_filtered_bessel_tail_masses.py

    python certify_filtered_mixed_columns.py --N 4096
    python certify_filtered_main_force_endpoint.py --out regenerated_endpoint.json
    python certify_filtered_true_source_schur.py --endpoint regenerated_endpoint.json
